TECHFEST LANDING PAGE CONCEPT
=============================
An unofficial creative landing page concept inspired by Techfest, IIT Bombay.
This is a design study and is not the official Techfest website.

FILES
- index.html — complete responsive website, including CSS and JavaScript.
- README.txt — these instructions.

FEATURES
- High-impact typography and lime/cyan visual identity
- CSS orbital graphic (no 3D assets or external libraries)
- Animated ticker, scroll progress, sticky navigation, reveal-on-scroll
- Interactive cursor glow on desktop
- Responsive layout and reduced-motion support
- Links to the official website: https://techfest.org/

RUN LOCALLY
Open index.html in a modern browser.

HOST ONLINE
Option A — GitHub Pages:
1. Create a GitHub repository (e.g. techfest-landing-page).
2. Upload index.html and README.txt.
3. In Settings → Pages, select deploy from branch, choose main and /(root).
4. Wait for the deployment URL to appear.

Option B — Netlify:
1. Extract the ZIP.
2. Visit https://app.netlify.com/drop and drag the folder into the page.
3. Copy the generated public URL.

DEMO RECORDING
Record a 30–60 second screen capture showing:
1. The hero and orbital animation.
2. Scrolling through the ticker and section transitions.
3. Hovering the three experience cards.
4. Clicking the official website CTA (you can stop before navigating away).
Upload the video to Google Drive and set General access to "Anyone with the link — Viewer".
